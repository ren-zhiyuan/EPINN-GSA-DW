# EPINN-GSA-DW
This repository contains the official implementation of the paper:

"Gradient-sensitivity-aware dynamic weighting for multi-task physics-informed neural networks: Theory and application to integral equations"
Zhiyuan Ren, Ruilong Yu, Yi Zeng, Shijie Zhou
(Submitted to Journal of Scientific Computing)

2.Getting Started
(1)Clone the repository
```text
git clone https://github.com/ren-zhiyuan/EPINN-GSA-DW.git
cd EPINN-GSA-DW
```
(2)Set up the environment
We recommend using a conda environment or a virtual environment with Python 3.10+.
```text
conda create -n epinn python=3.9
conda activate epinn
pip install -r requirements.txt
```
(3)Install dependencies
The requirements.txt file includes:
```text
torch>=2.12.0
numpy>=2.2.0
scipy>=1.15.0
matplotlib>=3.10.0
pandas>=2.3.0
```
(4)Run an experiment
Each script is self‑contained. For example, to train GSA‑DW on Eq.D:
```text
cd GSA-DW
python Eq_D.py
```
To run any baseline, similarly navigate to its folder and execute the corresponding script.
```text
All scripts will:
--Generate training/validation/test data on the fly (Sobol sequences).
--Train the networks with the specified method.
--Save validation loss curves as CSV files (in the current directory).
--Produce final test metrics (MSE, MAE, L2RE) and plot visualisations (saved as PDF/PNG in the ../figs/ directory).
```
